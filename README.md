# Horai

Escalas de trabalho: o mês de folgas e o dia de cada cargo, cobrindo a demanda hora a hora.

## Baixar

**[Baixar o Horai para Windows](https://github.com/LeMaq/horai-releases/releases/latest/download/Horai-win-x64.zip)** (sempre a versão mais nova)

1. Descompacte o zip e dê dois cliques em `Horai.exe`. Não precisa instalar nada.
2. Na primeira vez, o Windows pode avisar que o app não é reconhecido: clique em
   **Mais informações** e depois em **Executar assim mesmo**.

## Atualizações

O Horai procura versão nova sozinho quando abre. Quando houver, aparece o botão
**Atualizar para X.Y.Z** no topo: ele mostra o que mudou, baixa, confere o arquivo e reinicia.
O trabalho aberto fica guardado. Também dá para procurar à mão em **Arquivo › Procurar atualização**.

As versões anteriores e o que mudou em cada uma estão em [Releases](https://github.com/LeMaq/horai-releases/releases).
